# 饰品系统指南

这是一套255定制化的更华丽美化装备。通过挑战副本，获取图纸，制造饰品装备。 侦探憨，白百合憨……穿上它们，你也可以变成憨色！ 

## 一. 图纸获取

使用命令

**/res tp sj.s**

前往副本，击杀坚守者有概率掉落道具**混沌图纸**

![混沌图纸](/imgs/curios/混沌图纸.png)

## 二. 图纸使用

将图纸放到切石机里，可以切出多种图纸

![切石机](/imgs/curios/切石机.png)

将图纸与[奶粉](./curios#奶粉)，各种装备一起锻造，可以形成新的饰品，饰品会保留原装备上的附魔，属性等

::: info

如果需要铁砧维修，请使用锻造时使用的装备**原修复材料**

例如使用铁头盔锻造的帽子，请使用铁锭修复

:::

如果你切制时手误，可以使用[奶粉](./curios#奶粉)加上图纸在工作台重新合成为**混沌图纸**

![奶粉合成](/imgs/curios/奶粉合成.png)
