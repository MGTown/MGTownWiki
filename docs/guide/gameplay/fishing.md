# 趣味钓鱼指南

欢迎来到毛怪小镇全新升级的**趣味钓鱼**系统！这里不仅有数十种生活在各大生态环境中的奇珍异兽，更引入了张力搏斗、节奏判定、深渊虚空垂钓、地狱熔岩钓鱼、多方块祈福图腾以及渔市交易行等海量玩法。

---

## 一、 快速入门与基础交互

### 1. 甩竿与咬钩
1. 手持任意钓竿，朝向水面、岩浆或虚空深渊右键抛竿。
2. 当浮标产生水花飞溅、气泡翻涌或咬钩提示时，立刻右键提竿进入**收线搏斗小游戏**。
3. 成功完成小游戏即可将猎物拉出水面！

### 2. 专属钓具袋 (Fishing Bag)
服务器为每位钓鱼爱好者配备了专属的便携钓具背包，用于存放各类钓竿、钓钩、诱饵与探测仪器。
- 输入指令打开钓具袋：
  ```bash
  /cf bag
  ```
- 拥有对应权限时，钓获道具时可直接自动收纳进入钓具袋，不再占用主背包空间。

### 3. 海产集市交易行 (Fish Market)
捕获到的新鲜鱼获可以运送至渔市出售换取通用货币**憨币**！
- 打开海产集市界面：
  ```bash
  /cf market
  ```
- **定价机制**：鱼类的售价由 `基础价格 + 体长加成系数 × 实际体长` 共同决定。鱼儿体型越庞大、品质星级（普通/白银之星/黄金之星）越高，可卖出的憨币越丰厚！
- **一键出售**：集市界面提供了一键批量出售背包与钓具袋所有鱼获的功能。

### 4. 每日争霸赛与周末钓鱼大赛
- **每日海王巨物赛 (`daily_max_size_derby`)**：
  - 每天 **12:30 / 18:30 / 21:30** 开赛，比赛比拼单条鱼的最大体长！钓起巨兽可斩获丰厚憨币奖励与至高海王荣耀。
- **周末钓鱼争霸赛 (`weekend_competition`)**：
  - 周六、周日定时开启，比拼钓鱼总数量与积分。

## 二、 钓鱼小游戏搏斗机制 (Minigames)

咬钩后会根据不同水域和鱼种性格触发专属的博弈挑战：

| 游戏类型 | 机制说明 | 对应代表鱼种 | 操作技巧 |
| :--- | :--- | :--- | :--- |
| **精准判定 (Accurate Click)** | 游标在判定条左右滑动，在游标落入高分绿区时右键收线 | 淡水常规鱼、彩虹鱼 | 专注预判游标速度，切勿急躁狂点 |
| **张力拔河 (Tension)** | 保持钓线张力在安全绿区，防止脱钩或拉断钓线 | 海洋巨兽、鲨鱼、大王乌贼 | 鱼儿挣扎时松线，鱼儿疲惫时按住潜行收线 |
| **急速连击 (Click)** | 在规定倒计时内以最快手速连续右键点击收线 | 雷霆电鳗、暴龙鱼、旗鱼 | 快速爆发点击，快速耗尽鱼的体力 |
| **音游节拍 (Dance)** | 屏幕上方提示方向与动作序列，按顺序输入对应操作 | 虚空星核鱼、九天灵鲤、紫颂乌贼 | 依次输入：`左键`、`右键`、`跳跃`、`潜行`，按错即刻脱钩 |
| **蓄力跟随 (Hold)** | 长按右键维持浮标平衡，使指示条紧紧跟随挣扎的鱼身 | 熔岩翻车鱼、黑曜熔岩鱼类 | 把握提竿与松线节奏，保持光标重合 |

### 2. 特色钓钩 (Hooks)

可在钓竿上装备特化鱼钩，消耗耐久提供强大词缀：
- **精制钓钩**：精工抛光，提升高品质星级鱼类咬钩几率。
- **虚空折跃钓钩**：将任意普通钓竿升级为具备**虚空垂钓**能力的虚空神竿。
- **耐火黑曜重钩**：纯黑曜石打造，使任意钓竿具备**岩浆垂钓**能力。
- **聚财镀金磁钩**：带有金精磁力，大幅提升黄金之星与好运鱼类的产出率。
- **轻灵羽丝钓钩**：入水轻灵无声，搏斗游戏难度大幅度降低 (-15)，额外赠送 4 秒博弈时间。
- **深渊重铅沉钩**：专攻深渊与海沟，提升深海大鱼咬钩率，钓获体长额外增加 15%。

> [!TIP]
> **钓钩装配方式**：将钓钩拿在手上，**对着背包或快捷栏中的钓竿右键点击**，钓钩的词缀与耐久就会自动镶嵌到钓竿上，并会在钓竿 Lore 处实时显示剩余使用次数。

### 3. 特色诱饵 (Baits)

- **简易诱饵**：温和稳定，降低垂钓难度。
- **磁力诱饵**：缩短 10% 咬钩等待时间，游戏时间 +2 秒。
- **荒野狂暴诱饵**：大幅提高钓获体长 (+50%)，但游戏难度增加。
- **末影虚空诱饵**：虚空专属神饵，缩短 30% 虚空等待时间，大幅吸引虚空异种。
- **炽热熔岩诱饵**：熔岩专用高热饵料，缩短 35% 岩浆咬钩等待时间。
- **风暴雷鸣诱饵**：雷雨天专属，大幅引诱雷霆电鳗与远古传说海怪。
- **深海荧光诱饵**：夜间与深海发光诱饵，点亮漆黑海沟，吸引巨兽。
- **万灵金蚕玉饵**：奢华贡品饵料，专用于突破黄金之星最高品质。

1. **观察环境再下竿**：满月之夜前往大洋、雷暴天在河流蹲守电鳗、潜行深入地下深板岩，往往能钓到平时见不到的神秘稀客。
