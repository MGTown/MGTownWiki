# 趣味钓鱼

本服务器的钓鱼系统覆盖淡水、大洋、冻洋、洞穴、沼泽、熔岩与虚空七类水域生态，目前收录五十余种专属鱼种。每种鱼获按普通、白银之星、黄金之星三档品质区分，体长与售价随机生成；除鱼类外，水域中亦可打捞到钓具箱、鱼钩、诱饵与稀有钓竿。

> [!IMPORTANT]
> 本系统未对原版钓竿开放。使用原版钓竿抛竿仅触发原版钓鱼流程，须更换专属钓竿（如新手钓竿、白银钓竿）后方可进入本系统。

## 一、基本流程

1. **装备**：将专属钓竿置于主手或副手（双手均持钓竿时以主手为准）。另一手可放置诱饵，未放置不影响正常垂钓。
2. **抛竿**：对水面、岩浆或虚空右键抛出浮标。不同水域对应不同鱼池，普通水面无法获得熔岩类鱼种。
3. **收线**：出现咬钩提示后立即右键，完成收线环节即视为钓获成功。
4. **拾取**：鱼获落于浮标所在位置，须自行拾取；打捞箱则直接进入背包，鱼钩袋与鱼饵袋落于浮标处，仍须自行拾取。

> [!NOTE]
> 基岩版客户端（经 Geyser 接入的手机、平板等）将跳过收线环节，咬钩后直接获得鱼获。

## 二、常用指令

| 指令          | 说明                                           |
| :------------ | :--------------------------------------------- |
| `/fishingbag` | 打开专属钓具袋，用于存放钓竿、诱饵与钓钩等钓具 |
| `/sellfish`   | 打开鱼市场，将鱼获兑换为憨币                   |

钓具袋支持存放钓竿、诱饵、钓钩及各类钓鱼道具，**不支持存放鱼获与打捞箱**。袋内诱饵在手中未持有诱饵时自动生效；钓竿须实际持于手中方可使用。

## 三、品质与售价

- 每条鱼获的体长随机生成，同种鱼体长越大，售价越高。
- 品质分为普通、白银之星、黄金之星三档；品质越高，体长区间与售价上限越高。
- 售价同时受**体长加成**（寒霜极冰钓竿、荒野狂暴诱饵、深渊重铅沉钩等）与**品质加成**（白银钓竿、黄金钓竿、聚财镀金磁钩、海之眷顾附魔等）影响，两类加成可叠加。
- 每日卖鱼收益存在上限，具体数据以游戏内为准，超出部分当天无法售卖。
- 出售须在 `/sellfish` 界面内完成：将鱼获放入中间格位，点击下方「出售鱼」按钮。原版鱼及树枝、海草等杂物无收购价，无法放入；打捞箱本身具有价格，可直接出售。
- 钓获会自动标记归属（记录钓到它的玩家）。出售时，属于他人的钓获会被折价或拒收，只有本人钓获按原价结算。

## 四、钓具一览

### 钓竿

| 钓竿         | 特性                                             |
| :----------- | :----------------------------------------------- |
| 新手钓竿     | 咬钩等待延长，收线难度降低，适用于入门阶段       |
| 白银钓竿     | 提高白银之星品质的出现概率                       |
| 黄金钓竿     | 提高黄金之星品质的出现概率                       |
| 群星钓竿     | 提高幸运类鱼种的出现概率                         |
| 大师钓竿     | 咬钩等待缩短并附带双品质加成，同时提高收线难度   |
| 白骨钓竿     | 支持岩浆垂钓，并会引来水下骷髅                   |
| 炽焰地狱钓竿 | 支持岩浆垂钓，提高熔岩类鱼种与黄金之星的产出     |
| 虚空幽影钓竿 | 支持虚空垂钓，提高虚空系鱼种的产出               |
| 风暴雷霆钓竿 | 雨天与雷暴天气下咬钩等待大幅缩短，偏向雷暴系鱼种 |
| 寒霜极冰钓竿 | 鱼获体长提高                                     |
| 海神潮汐钓竿 | 一定概率触发双重渔获                             |

> 风暴雷霆钓竿与寒霜极冰钓竿可从精制钓具箱中低概率开出；虚空幽影钓竿与炽焰地狱钓竿可从深渊宝藏箱中低概率开出。海神潮汐钓竿须持鲸元券前往商业街抽奖机抽取。其余款式不属钓鱼战利品，须通过商店或活动获取。

### 钓钩

钓钩装配于钓竿后生效，具有使用次数上限，次数耗尽后消失，钓竿 Lore 处会显示剩余次数。现有钓钩包括：精制钓钩（双品质小幅加成）、聚财镀金磁钩（提高黄金之星与幸运类鱼种产出）、轻灵羽丝钓钩（显著降低收线难度）、深渊重铅沉钩（体长提高）、虚空折跃钓钩（支持虚空垂钓）、耐火黑曜重钩（支持岩浆垂钓），以及两枚自岩浆与虚空中打捞所得的沉没旧钩；沉没旧钩使用次数较少，建议仅作应急替代。

**装配方式（生存模式）**：以鼠标拾起钓钩后，直接左键点击背包内的钓竿即可完成装配；空手右键钓竿可取下，剩余次数保留。

### 诱饵

诱饵置于另一手或钓具袋内生效，每次抛竿消耗 1 个。各类诱饵侧重不同：简易诱饵降低收线难度；磁力诱饵缩短咬钩等待；荒野狂暴诱饵提高鱼获体长；深海荧光、风暴雷鸣、炽热熔岩、末影虚空四类诱饵分别偏向对应水域生态；万灵金蚕玉饵偏向黄金之星品质。

### 附魔

钓竿附带的**海之眷顾**（提高品质）与**饵钓**（缩短岩浆、虚空垂钓的咬钩等待）对本系统生效。

## 五、打捞箱

水域中可打捞到容器，开启后随机获得钓具、诱饵或材料。每件奖励独立判定，存在空箱可能。

| 容器         | 出没水域       | 稀有产出                             |
| :----------- | :------------- | :----------------------------------- |
| 精制钓具箱   | 主世界水体     | 风暴雷霆钓竿、寒霜极冰钓竿           |
| 沉没鱼钩袋   | 主世界水体     | 耐火黑曜重钩、虚空折跃钓钩           |
| 秘法鱼饵袋   | 主世界水体     | 万灵金蚕玉饵                         |
| 深渊宝藏箱   | 深海海底       | 虚空幽影钓竿、炽焰地狱钓竿、海洋之心 |
| 炼狱保险箱   | 下界岩浆       | 沉没黑曜石钓钩、远古残骸             |
| 虚空遗物立方 | 末地与底层虚空 | 虚空折跃钓钩、末影水晶、龙蛋         |

### 出现条件

各类容器并非在所有水域中均有机会打捞。系统按水域生态将容器分置于若干条相互独立的条件链，容器自身条件与所在水域条件须**逐层同时满足**方可进入抽取范围；任一环节不符，该容器便不会出现在本次鱼获之中。

#### 水面容器

精制钓具箱、沉没鱼钩袋与秘法鱼饵袋三者共用同一组条件：

- **浮标落于水中**，且垂钓水域属主世界水体，岩浆与虚空不计入内。
- **须持专属钓竿**。原版钓竿不参与本系统，详见文首说明。

三者不限定具体水体类型，淡水河流、湖泊、沼泽、地下水域与大洋均可打捞；差别仅在于同一水域内其他鱼获的构成不同，容器本身的出现条件并无区别。

#### 深海容器

深渊宝藏箱在水面容器条件的基础上另行附加两项限制：

- **群系属海洋**：浮标所在群系须为海洋类群系，涵盖浅海、深海、寒冷与冻洋、温水及暖水海洋。
- **垂钓者处于深海海底**：此条以**玩家自身所处高度**判定，须潜至 Y ≤ 30。

二者须同时成立。垂钓者若立于岸上、船上或海面平台抛竿，即便浮标落入深海，亦不会产出该容器；反之，淡水水域、溶洞与地下暗河纵使位置足够深，因不属海洋群系，同样无从打捞。

#### 熔岩容器

炼狱保险箱仅于下界产出，条件如下：

- **浮标落于岩浆中**。
- **所用钓具具备熔岩垂钓能力**，如白骨钓竿、炽焰地狱钓竿，或装配耐火类钓钩。
- **垂钓所在世界为下界**。

主世界熔岩湖虽同样可以垂钓，但仅产出原石、黑曜石一类基础材料与黑曜系鱼种，不产出炼狱保险箱。

#### 虚空容器

虚空遗物立方适用于全部虚空水域，不限于特定世界：

- **浮标落于虚空中**。
- **所用钓具具备虚空垂钓能力**，如虚空幽影钓竿，或装配虚空类钓钩。

末地岛屿边缘的虚空与世界底层的虚空均可打捞，两处共用同一份虚空鱼池，可获得的鱼种完全一致。

> [!NOTE]
> 打捞箱钓中后直接进入背包，无须拾取；鱼钩袋与鱼饵袋则落在浮标处。打捞箱、鱼钩袋与鱼饵袋均属战利品而非鱼获，不具鱼获所特有的体长与品质，不参与以体长计分的赛事，但可于鱼市场正常出售。

## 六、钓鱼赛事

赛事每日仅开启一场；开赛后首次成功钓获即自动参赛。

| 赛事                       | 时间          | 比拼内容     | 排名奖励     |
| :------------------------- | :------------ | :----------- | :----------- |
| 每日钓鱼大赛（周一至周六） | 10:00 ~ 22:00 | 每场随机抽取 | 以游戏内为准 |
| 周末钓鱼大赛（周日）       | 20:00 ~ 21:00 | 每场随机抽取 | 以游戏内为准 |

- 两场赛事的比拼目标均在开赛时从候选池中随机抽取，并随开赛播报与实时榜单公布。
- 计分口径随目标而变：比拼体长或总长度时，无体长的战利品（如打捞箱）不计分；比拼数量类目标时，符合该目标类别的每次钓获计 1 分。
- 每日钓鱼大赛无人数门槛；周末钓鱼大赛须在线人数满 2 人方可开赛，人数不足时当日取消。周末赛期间全服咬钩等待缩短 15%。
- 成绩相同时，后达成该成绩者名次在前。
- 奖励以游戏内为准，前五名均有奖励；奖励于结算时发放，在线玩家当场获得，离线玩家于下次登录时补发。

## 七、各生态鱼种

- **淡水河流与湖泊**：金鱼、河鲈、鲻鱼、鲤鱼、鲇鱼、苔原巨鲈、北极红点鲑、祥瑞金锦鲤。此外，樱花树林水域产出樱花大马哈鱼，雨天与雷暴天气产出雷霆电鳗，夜间产出幽灵鲇，丛林及竹林溪流产出竹溪碧雀鳝，高空水域（Y ≥ 120）夜间产出九天星穹苍龙鲤。
- **大洋与深海**：金枪鱼、白斑狗鱼、沙丁鱼、章鱼、翻车鱼、红鲷鱼、巨浪双髻鲨、蓝水母、粉水母、荧光水母。暖水海洋产出红宝石小丑鱼，冻洋产出极地霜花鳟与冰川帝王巨蟹，极夜产出极光幻彩极鳍鱼，深海海底产出深渊灯笼鮟鱇与远古腔棘鱼，乘船远洋产出极速旗鱼与大王酸浆乌贼，满月夜间产出银月魔鬼鱼，雷暴天气的深海产出幼年利维坦。
- **洞穴与深板岩**：鲟鱼、无目洞穴脂鲤、紫晶簇孔雀鱼、滴石针鳞鲇；在深板岩层潜行垂钓时，可产出幽匿刺脊鱼。
- **沼泽与红树林**：林跃鱼、泥沼潜伏肺鱼、远古鳄雀鳝、女巫密酿躄鱼。
- **下界与岩浆海**：黑曜熔鳞翻车鱼、虚空鲑鱼、烈焰流火鳐、绯红巨颚暴龙鱼；灵魂沙峡谷产出幽魂青炎鳗，玄武岩三角洲产出玄武鎏金帝王鲤。
- **末地与虚空**：虚空漂流鳐、紫颂星体乌贼、星云游荡水母，以及传说级鱼种奇点坍缩星核鱼。
- **特殊**：彩虹七彩神鱼出现于淡水水域，须命中指定颜色方计为钓获。

> 除上述鱼种外，水域中亦会产出树枝、海带、燧石、金锭等杂物，均无收购价。使用白骨钓竿垂钓时，夜间水面会引来水下骷髅，岩浆中会引来溶岩凋灵骷髅。

## 八、实用建议

1. **环境条件影响产出**：天气、时间、深度与群系会显著提高对应鱼种的出现概率，满月、雷暴、夜间、深海海底与高空水域尤甚，建议下竿前确认环境。
2. **特定状态只影响权重**：深板岩层潜行垂钓时幽匿刺脊鱼更易上钩；乘船出海时极速旗鱼、大王酸浆乌贼与幼年利维坦更易上钩。这类状态只提高出现概率，并非硬性门槛。
3. **品质加成可叠加**：钓竿、钓钩、诱饵与海之眷顾附魔可同时生效，需要提升高品质产出时建议组合使用。
4. **体长对售价的影响高于品质**：寒霜极冰钓竿、荒野狂暴诱饵与深渊重铅沉钩同时使用时，同一条鱼获的售价可提高至两倍以上。
5. **岩浆与虚空垂钓须配备对应装备**：岩浆垂钓需白骨钓竿、炽焰地狱钓竿或耐火类钓钩；虚空垂钓需虚空幽影钓竿或虚空类钓钩，装备不符时无法产出对应鱼种。
