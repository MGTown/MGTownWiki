# 附魔

宝藏附魔为紫色词条，普通附魔为白色词条，生存模式下一件物品只能拥有一个宝藏附魔

## 模糊(blur)

| 字段         | 内容           |
| ------------ | -------------- |
| **类别**     | 附魔           |
| **词条类型** | 宝藏附魔       |
| **位置**     | 剑             |
| **等级**     | 1              |
| **冲突**     | 无             |
| **描述**     | 手持时隐藏自身 |
| **冷却时间** | 无             |
| **获取途径** | 无法获得       |
