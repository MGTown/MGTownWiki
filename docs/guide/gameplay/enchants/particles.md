# 粒子

黄色词条，位于工具处在攻击生物或破坏方块时在被攻击的生物或方块处产生粒子，位于弓、弩、三叉戟处时还会随弹道产生粒子，位于长矛处时还会在冲锋时留下轨迹，位于鞘翅处飞行时鞘翅两侧产生粒子。

| 字段     | 内容                                                           |
| :------- | :------------------------------------------------------------- |
| 位置     | 剑、矛、斧、镐、铲、锄、重锤、三叉戟、弓、弩、钓竿、剪刀、鞘翅 |
| 等级     | 1                                                              |
| 冲突     | 生存模式下粒子附魔相互冲突                                     |
| 描述     | 附加`{particle}`粒子                                           |
| 获取途径 | 所有途径均可获取                                               |
