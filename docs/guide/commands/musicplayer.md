# 点歌

服务器的点歌插件，音源为网易云音乐，支持搜索歌曲并加入公共播放队列。

> [!IMPORTANT]
> 收听音乐与歌词需要安装小镇客户端（内置 MusicPlayer 模组）或独立安装（MusicPlayer客户端模组见[毛怪小镇QQ群](https://qm.qq.com/q/JSzjMcoNKq)群文件）。未安装模组的玩家听不到声音，但屏幕顶部的歌曲进度条依然可见，搜索、点歌、排队等功能也不受影响。

## 点播歌曲

`/music <歌曲ID>`直接点播（填网易云歌曲 ID）

`/music <分享链接>`粘贴网易云分享链接点歌（自动从链接中解析歌曲 ID）

`/music <平台> <歌曲ID>`指定音源点播（当前仅支持 `netease`）

点播成功后歌曲会加入公共播放队列，聊天栏会提示它在队列中的位置。

## 搜索与选歌

`/music search <歌名或歌手>`搜索歌曲（返回前 30 条）

`/music search <平台> <关键词>`指定音源搜索（如 `/music search netease 晴天`）

`/music select <序号>`播放上一轮搜索结果中的第 N 首

> [!TIP]
> 搜索结果中每条都带有可点击的「▶ 点播」，直接点击即可播放，无需手动输入 `/music select`。

## 播放队列

`/music list`查看正在播放和排队等待的歌曲

`/music cancel <序号>`撤回自己点播的队列歌曲

> [!TIP]
> 队列中属于自己的曲目带有可点击的「✕ 取消」，点击即可撤回。

## 个人控制

`/music mute`开启 / 关闭个人静音（只对自己生效，不影响他人收听）
