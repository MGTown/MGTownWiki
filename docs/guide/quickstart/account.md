# 账号与密码

来到毛怪小镇的第一件事，就是为自己注册一个账号。下面说明密码规则与注册时的注意事项。

## 密码要求

密码需要同时满足下列全部条件：

| 项目     | 要求                              |
| -------- | --------------------------------- |
| 长度     | 5 – 32 位                         |
| 数字     | 至少 1 个                         |
| 大写字母 | 至少 1 个                         |
| 小写字母 | 至少 2 个                         |
| 特殊字符 | 至少 2 个，且**仅限** `!@#$%^&*?` |

符合上述要求的密码示例：`MaoGuai2021!@`

> [!DANGER]
> 这个示例只用来演示**格式**，请不要直接拿它当密码。文档是公开的，谁都能看到它——用它等于把账号拱手让人。请自己另想一个满足规则、且只有你知道的密码。

> [!NOTE]
> 特殊字符只认可 `!` `@` `#` `$` `%` `^` `&` `*` `?` 这 9 个符号。下划线 `_`、空格、中文标点等都不计入特殊字符数量。

## 账号注册

- 昵称只能由**字母、数字、下划线**组成。
- 注册过程中，如果被**直接要求输入密码**，说明你填写的昵称已经被占用了，换一个昵称重新注册即可。

> [!TIP]
> 取昵称时建议先想好两三个备选，遇到重名就不用临时纠结啦。

若在注册或登录过程中遇到其他问题，可加入[官方 QQ 群](https://qm.qq.com/q/JSzjMcoNKq)咨询管理员。
